# Auto_Tinify - 项目概述

## 1. 项目介绍

Auto_Tinify 是一款专为 Adobe After Effects 设计的图片压缩工具脚本。它通过集成 Tinify API（即知名的 TinyPNG/TinyJPG 服务），为 AE 用户提供高效、智能的图片压缩解决方案。

本脚本旨在解决 After Effects 项目中图片资源体积过大的问题，帮助用户在不损失视觉质量的前提下，显著减小项目文件大小，提升项目性能和协作效率。

## 2. 设计目标

### 2.1 核心目标
- **高效压缩**：利用 Tinify API 的先进压缩算法，实现高质量图片压缩
- **无缝集成**：作为原生 AE 脚本，与 After Effects 完美融合
- **智能管理**：自动处理多个 API Key，避免调用限制
- **用户友好**：提供直观的 ScriptUI 面板和便捷的操作流程

### 2.2 用户体验目标
- **简单快捷**：最少的操作步骤完成压缩任务
- **实时反馈**：清晰的进度指示和状态显示
- **灵活配置**：支持自定义路径和批量处理
- **稳定可靠**：完善的错误处理和恢复机制

## 3. 核心功能

### 3.1 主要功能
1. **智能压缩**
   - 支持 JPG、PNG、WebP 格式
   - 保持视觉质量的同时最大化压缩率
   - 自动检测图片格式并应用最佳压缩算法

2. **多密钥支持**
   - 支持多个 Tinify API Key
   - 自动轮换使用，避免单个 Key 的调用限制
   - 实时显示每个 Key 的剩余调用次数

3. **路径配置**
   - 支持变量 `${projectPath}` 表示项目目录
   - 支持正则表达式匹配文件路径
   - 灵活配置输入和输出路径

4. **批量处理**
   - 支持单个文件、多个文件或整个文件夹
   - 并行处理提升效率
   - 进度跟踪和错误处理

5. **实时监控**
   - 状态栏显示剩余压缩次数
   - 实时显示当前处理路径
   - 详细的日志记录

### 3.2 快捷操作
- `Ctrl+Shift + 点击`：仅压缩选中的图片文件
- `Alt + 点击`：直接替换原图（压缩后覆盖原文件）

## 4. 技术栈概述

### 4.1 核心技术
- **ExtendScript**：Adobe 官方脚本语言，兼容 After Effects CC 2020+
- **ScriptUI**：Adobe 脚本 UI 框架，创建原生风格的界面
- **Tinify REST API**：图片压缩服务接口
- **JSON**：配置文件存储格式

## 5. 兼容性与要求

### 5.1 系统要求
- **操作系统**：Windows 10/11 或 macOS 10.14+
- **After Effects**：CC 2020 (版本 17.0) 或更高版本
- **网络连接**：需要访问 Tinify API（api.tinify.com）

### 5.2 文件格式支持
- **输入格式**：JPG、JPEG、PNG、WebP
- **输出格式**：与输入格式相同（自动保持格式一致性）
- **最大文件大小**：受 Tinify API 限制（128MB）

### 5.3 API 限制
- **免费额度**：每月 500 次压缩（每个 API Key）
- **付费计划**：可购买额外调用次数
- **速率限制**：API 调用频率限制（详见 Tinify 官方文档）
