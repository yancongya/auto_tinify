# Auto_Tinify

主打简单快捷的After Effects 图片压缩工具

## 功能特点

- 使用 Tinify API 压缩图片（JPG、PNG、WebP）
- 支持多 API Key 轮换，自动追踪剩余次数
- 支持路径配置，使用 ${projectPath} 变量
- Ctrl+Shift 点击：压缩选中的图片文件
- Alt + 点击：直接替换原图

## 使用方法

1. 下载 `public` 文件夹中的 `auto_tiny2.0.4.jsxbin` 文件
2. 将文件复制到 After Effects 的脚本目录：
   - Windows: `C:\Program Files\Adobe\Adobe After Effects [版本]\Support Files\Scripts\`
   - Mac: `/Applications/Adobe After Effects [版本]/Scripts/`
3. 重启 After Effects
4. 在 `Window` 菜单中找到脚本

## 获取 API Key

访问 [Tinify 官网](https://tinify.com/developers) 获取免费的 API Key
