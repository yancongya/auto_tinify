常见问题

解答您可能遇到的问题

压缩失败通常有以下原因：1. API Key 无效或已过期；2. 网络连接问题；3. 图片格式不支持。请检查 API Key 是否正确，网络连接是否正常，以及图片格式是否为 JPG、PNG 或 WebP。

Tinify 每月提供 500 次免费压缩额度。如果用完，可以：1. 等待下个月额度重置；2. 注册新账号获取新的 API Key；3. 在 Auto_Tinify 中配置多个 API Key 进行轮换使用；4. 升级 Tinify 付费计划。

Auto_Tinify 支持压缩 JPG、PNG 和 WebP 格式的图片。这些是 After Effects 中最常用的图片格式，压缩后可以保持良好的视觉质量同时减小文件大小。

是的，Auto_Tinify 支持批量压缩。您可以在 After Effects 项目中选择多个图片文件，然后使用 Ctrl+Shift+点击"开始压缩"按钮进行批量压缩。压缩后的文件会保存在您设置的输出路径中。
