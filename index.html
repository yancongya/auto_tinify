工作流程

三步 开始使用

简单直观的操作流程，3 个步骤即可开始压缩

1

安装脚本

选择以下任一方法安装 Auto_Tinify：

方法 1：手动安装
下载 .jsxbin 文件 → 复制到 AE/PS 脚本目录 → 重启软件
方法 2：脚本面板
在 AE 中打开脚本面板 → 拖拽 .jsxbin 文件安装
方法 3：kbar 管理器（推荐）
在 kbar 中进行配置 Auto_Tinify → 一键调用
2

配置设置

添加 Tinify API Key，配置要压缩的图片路径，支持变量和正则表达式。（默认项目旁边的“输出”文件夹）

添加 API Key
配置压缩路径
自动保存配置
3

开始压缩

点击"开始压缩"按钮，或使用 Ctrl+Shift 导出选中图层进行压缩，Alt 压缩素材文件。

点击开始压缩，询问替换或后缀保存
Ctrl+Shift 导出选中图层并压缩
Alt 压缩选中的素材文件（AE）

常见问题

有问题？ 这里有答案

请检查：
1. API Key 是否有效且未过期
2. 网络连接是否正常
3. 图片格式是否支持（JPG、PNG、WebP）
4. 查看日志面板获取详细错误信息

Tinify 每月提供 500 次免费压缩。如果用完：
1. 等待下个月额度重置
2. 注册新账号获取新的 API Key
3. 在快点鸭Auto_Tinify中配置多个 API Key 轮换使用
4. 升级 Tinify 付费计划
